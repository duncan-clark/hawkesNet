**hawkesGrowthNet** is an R package that provides tools for simulating and analyzing network that grow with **Hawkes process** arrival times.

- Generate events under various Hawkesian network growth formulations
- Estimate model parameters for hawkesGrowhtNet models
- Visualize network growth over time (if you have custom plotting functions)
